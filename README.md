✨ Descripción general

 Sistema web completo que replica el funcionamiento real de un comercio.

Está diseñado para que:

 El jefe administre stock, precios y ganancias

 Los empleados registren ventas de forma rápida y segura

 El stock se mantenga siempre actualizado

 El cierre de caja muestre resultados claros del día
